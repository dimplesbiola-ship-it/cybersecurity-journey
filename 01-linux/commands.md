# Linux Commands

## Navigation

pwd
- Shows the current directory.

ls
- Lists files and directories.

cd
- Changes directory.

## Files and directories

mkdir
- Creates a directory.

touch
- Creates a file.

cp
- Copies files.

mv
- Moves or renames files.

rm
- Removes files.

## System information

whoami
- Shows the current user.

uname -a
- Shows system/kernel information.

ip addr
- Shows network interface information.

## Security relevance

Linux commands are important in cybersecurity because
security analysts and penetration testers frequently work
with Linux systems and command-line tools.
